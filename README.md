# UFEST Puntos — FestivalManager

En el Estado 2 de UFEST Puntos corregimos la base del proyecto y construimos su parte pública. Creamos un entorno virtual con sus dependencias en `requirements.txt` y regeneramos las migraciones para que la base de datos coincida con los modelos. Agregamos un tema de colores para cada evento, que se elige desde el panel de administración. Configuramos el sitio en español y con la hora de Colombia. Implementamos el registro, el inicio y el cierre de sesión, y un perfil donde cada participante ve su total de puntos y su historial agrupado por evento. También construimos las páginas públicas: la lista de eventos, el detalle de cada evento con sus actividades y filtros, y el detalle de cada actividad. En todas, el público solo ve el contenido publicado.
