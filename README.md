# UFEST Puntos — FestivalManager

En el Estado 3 se agrega el rol de coordinador quien se encarga de manejar las actividades de los eventos como publicarlos, especificar detalles como horarios, lugar, descripción, foto de portada, etc. También se encargan de tomar la asistencia de los participantes mediante QR, función que también se implementa en este estado
